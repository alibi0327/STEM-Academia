STEM Academia — несколько курсов на одну учетную запись

Что изменится:
- в списке учителей появится кнопка «+ Добавить курс»;
- новый логин/пароль не создается;
- уже назначенные курсы нельзя назначить повторно;
- кабинет учителя показывает все его курсы;
- прогресс и тесты считаются отдельно по каждому курсу.

Установка:
1. Скопировать admin.html, js/admin.js, js/teacher.js и supabase/migrations/003_multi_course.sql.
2. Commit + Push.
3. Supabase SQL Editor → выполнить 003_multi_course.sql.
4. Обновить страницу админки.
