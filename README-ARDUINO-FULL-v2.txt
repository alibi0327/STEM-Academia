STEM Academia — Arduino FULL v2

Новая программа: 17 последовательных занятий.
От знакомства с Arduino до:
- установки Arduino IDE;
- подключения Arduino Uno к компьютеру;
- выбора Board/Port;
- запуска встроенного Blink;
- понимания setup(), loop(), delay();
- breadboard;
- внешнего LED и резистора;
- управления LED;
- кнопки;
- analogRead;
- PWM;
- Serial Monitor;
- первого мини-проекта;
- итогового теста (16 вопросов, проходной балл 80%).

ВАЖНО:
005_arduino_full_v2.sql заменяет старую программу Arduino и сбрасывает только прогресс/тест/сертификат курса Arduino, чтобы новая версия проходилась с начала.
LabDisc и ROQED не затрагиваются.

Установка:
1. Скопировать файлы ZIP в STEM-Academia.
2. Commit + Push.
3. Выполнить supabase/migrations/005_arduino_full_v2.sql в Supabase SQL Editor.
4. Ctrl+F5 на сайте.
