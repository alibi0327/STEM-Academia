# STEM Academia

Первая версия учебной платформы.

## Что уже есть
- Вход через Supabase Auth
- Определение роли admin / teacher
- Панель администратора
- Школы
- Просмотр учителей
- Курсы
- Результаты
- Сертификаты
- Кабинет учителя

## Подключение Supabase
Откройте `js/config.js` и вставьте:
- SUPABASE_URL
- SUPABASE_ANON_KEY / publishable key

Никогда не вставляйте service_role key в клиентский код.
