STEM Academia — Arduino course patch

Добавляет:
- курс «Обучение работе с Arduino»
- 12 занятий
- итоговый тест из 12 вопросов
- проходной балл 80%
- прогресс и результаты в Supabase
- сертификат STEM-ARD-...
- отображение Arduino в кабинете учителя

Установка:
1. Скопировать содержимое ZIP в локальный репозиторий STEM-Academia.
2. Commit + Push origin.
3. Supabase → SQL Editor → выполнить supabase/migrations/004_arduino_course.sql.
4. Обновить сайт Ctrl+F5.
5. В админке Arduino появится среди доступных курсов и его можно будет добавить существующему учителю.
