STEM Academia — LabDisc BioChem FULL 50

ЧТО ИЗМЕНЕНО
- LabDisc расширен до 50 последовательных занятий.
- Практика начинается с физического знакомства с прибором.
- Далее: GlobiLab X, USB/Bluetooth, Logger Setup, первая запись, графики, таблица, сохранение.
- Затем: BioChem-датчики и безопасные учебные измерения.
- Затем: совместные измерения, автономная запись, Map View, Workbook, диагностика.
- Финал: самостоятельный STEM-проект, практическая аттестация и итоговый тест.
- Нет отдельного подтверждения практики.
- «Завершить занятие» сохраняет прогресс и открывает следующее занятие.

КАК УСТАНОВИТЬ
1. Распакуйте ZIP.
2. Откройте папку STEM-Academia-main внутри архива.
3. Скопируйте ВСЁ её содержимое в вашу локальную папку STEM-Academia с заменой файлов.
4. В GitHub Desktop проверьте Changes.
5. Summary: Add LabDisc BioChem full 50 lesson course
6. Нажмите Commit to main.
7. Нажмите Push origin.
8. В Supabase откройте SQL Editor.
9. Откройте файл supabase/migrations/021_labdisc_biochem_full_50.sql из нового проекта.
10. Скопируйте весь SQL в SQL Editor и нажмите Run.
11. Дождитесь Success.
12. Откройте сайт и выполните Ctrl+F5.
13. Зайдите учителем → LabDisc BioChem. Должно отображаться 50 занятий.

ВАЖНО
Миграция сохраняет существующий course slug `labdisc`, поэтому назначенные учителям курсы не нужно назначать заново.
